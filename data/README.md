# Данные

`runs/` предназначен для локальных исходных сессий и исключён из Git. Не переносить сюда реальные измерения других проектов. Синтетические fixtures будущих тестов должны явно маркироваться как synthetic и содержать параметры генерации/seed. Шаблон метаданных: [RUN_MANIFEST](../templates/RUN_MANIFEST.json).
