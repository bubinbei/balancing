# Переносимое ядро и будущая прошивка платы

Реализовано переносимое C99-ядро: CRC/упаковка BLC1, очередь захватов с явным переполнением, расширение TIMER timestamp и преобразование слов датчиков. [Native build и ограничения](BUILD.md). Это не образ NiceNano: SPI/GPIOTE/PPI/USB adapter, регистровая настройка датчиков и сервер команд ещё требуют аппаратной интеграции.

Сначала закрыть [G00](../tasks/G00-board-passport.md) и [G01](../tasks/G01-toolchain.md), затем следовать [архитектуре firmware](../docs/FIRMWARE.md). Ревизия клона, Flash layout и загрузчик пока неизвестны; готового UF2 и команды прошивки нет.
