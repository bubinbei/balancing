# G03 — один BMI160 по SPI

**Результат:** подтверждено чтение новых отсчётов одного BMI160 и конфигурации его регистров. Уровень: `device`; ротор неподвижен.

**Читать:** [README](../README.md), [STATE](../STATE.md), эту карточку, [HARDWARE](../docs/HARDWARE.md), [FIRMWARE](../docs/FIRMWARE.md), подтверждённый `hardware/pinmap.csv`. Таблицы регистров сверять с указанным в HARDWARE datasheet.

**Файлы:** `firmware/` драйвер одного датчика и стендовый режим, будущие `tests/firmware/`, `evidence/reports/G03.md`. Изменение pinmap — только с обновлением паспорта.

## Срезы

1. Проверить питание/логику 3,3 В, общую землю и модуль до подачи питания. Подключить один CS и DRDY по паспорту. Остальные CS держать неактивными.
2. SPI начать с 4 МГц. Прочитать идентификатор BMI160 (`CHIP_ID = 0xD1`) и регистры состояния; выполнить штатную последовательность запуска с задержками datasheet. Readback должен подтвердить диапазоны, Normal mode и ODR 800 Гц для accel/gyro.
3. Реализовать ограниченный по времени обработчик DRDY и неблокирующее чтение; не печатать USB из ISR. На этом этапе локальные timestamps ещё не считать полной приёмкой синхронизации G04.
4. Записать 60 секунд неподвижного датчика; затем шесть положений ±g для проверки осей/масштаба ускорения. Gyro проверять как угловую скорость, а не третий акселерометр. Указать температуру и прогрев.

## Приёмка

- `PASS`: ID и readback устойчивы на 1000 последовательных чтениях; нет ошибок SPI и зависаний по таймауту.
- `PASS`: в 60-секундном опыте каждый выданный sample соответствует новой готовности данных; счётчики DRDY, чтений и потерь согласуются. Реальную частоту сравнить с допуском внутреннего генератора datasheet, не требовать ровно 800,000 Гц.
- `PASS`: знаки осей во всех шести положениях правильны, норма g после простой калибровки отличается от 1g не более чем на 5%; отсутствие насыщения показано сырыми min/max. Это диагностический допуск, не окончательная метрология.
- `FAIL`: повторные чтения одного отсчёта считаются новыми, контакт CS/DRDY угадан или недоступные данные подставлены нулями без quality.

**Откат:** выключить питание, вернуть известный USB hello и один проверенный модуль; не менять несколько соединений одновременно. Сохранить неисправную конфигурацию в отчёте.

**Доказательства:** G03: схема подключения, ID/readback, напряжения, счётчики, сырая запись и её SHA-256, шесть положений и полученные знаки.
