# G00 — паспорт платы, модулей и ротора

**Результат:** факты о реальном оборудовании отделены от предположений; дальнейшая сборка имеет конкретную основу. Уровень доказательств: `documentation`; наблюдение платы без прошивки — `device` с указанным способом проверки.

**Читать:** [README](../README.md), [STATE](../STATE.md), эту карточку, [HARDWARE](../docs/HARDWARE.md), [MECHANICS](../docs/MECHANICS.md), [SOURCES](../docs/SOURCES.md). Максимум шесть проектных файлов; первичные схемы открывать только для выбранной детали.

**Изменяемые файлы:** будущие `hardware/board-passport.md`, `hardware/pinmap.csv`, `hardware/rotor-passport.md`, `evidence/reports/G00.md`; при необходимости уточнить `docs/HARDWARE.md`, затем контекст. Не переносить личные серийные номера в публичный паспорт.

## Срезы по порядку

1. Записать маркировку NiceNano, ревизию, оригинал/клон/неизвестно, доступные фото обеих сторон, источник схемы и способ загрузки. Не приравнивать надпись nRF52840 к полной совместимости с nice!nano.
2. Составить pinmap: контакты платы → GPIO микроконтроллера → SPI/CS/DRDY/фаза/индекс/USB. Учесть занятые загрузчиком, светодиодами и переключаемым питанием линии. Указать питание, логические уровни и отличия ревизий. Пока контакты не сверены со схемой и платой, статус каждой спорной строки `unverified`.
3. Создать паспорт двух BMI160 и двух LIS3DH: модуль, разводка питания, регуляторы/преобразователи, выведенные SPI и DRDY. Задать план проверки WHO_AM_I; реальное чтение относится к G03/G05.
4. Записать массу и габариты ротора/маховика/шкива, предполагаемые опорные шейки, радиусы и две плоскости коррекции; недоступные размеры оставить неизвестными. Выбрать предмет решения G06: полноценные металлические подшипниковые узлы или согласованная альтернатива.

## Приёмка

- `PASS`: у платы определены ревизия либо документированный статус клона, схема и способ подтверждения всех используемых GPIO; нет конфликтов контактов и предположения о допустимости 5 В.
- `PASS`: обозначены питание датчиков, четыре независимых CS/DRDY и два входа фазы/индекса; все ещё неизвестные соединения явно запрещены к сборке до проверки.
- `PASS` для начала G01: известны bootloader, board target и границы приложения либо есть проверяемый план их чтения без стирания. Если этих данных нет, G00 остаётся незавершённым для G01.
- `FAIL`: pinmap выведен только из похожего фото, тип платы угадан, заявлены отсутствующие измерения или неизвестная механика объявлена принятой.

**Откат:** сохранить исходные фото/сведения; отменить только собственные неподтверждённые записи. Устройство не менять.

**Доказательства:** `evidence/reports/G00.md` со ссылками на источники, таблицей `факт / как проверен / неизвестно`, ревизией pinmap и списком зависимых запретов. Полный G00 завершается после закрытия аппаратных неизвестных, нужных для следующих этапов.
