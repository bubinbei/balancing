# G01 — воспроизводимая сборка и USB hello

**Результат:** минимальное приложение для подтверждённой NiceNano собирается повторяемо; отдельный аппаратный срез проверяет USB CDC. Уровни: `build` для сборки/проверок карты памяти, `device` для запуска на плате.

**Читать:** [README](../README.md), [STATE](../STATE.md), эту карточку, [FIRMWARE](../docs/FIRMWARE.md), [HARDWARE](../docs/HARDWARE.md), подтверждённый `hardware/board-passport.md` из G00. Не начинать аппаратный срез с неизвестной платой.

**Файлы:** будущие `firmware/`, `firmware/BUILD.md`, `firmware/toolchain-lock.json`, `evidence/reports/G01.md`. Контекст обновить после каждого среза.

## Срезы

1. Выбрать и зафиксировать версию Zephyr/Nordic NCS, компилятор, board target и зависимости по паспорту. Записать команды подготовки чистой среды и точные версии; не использовать плавающий `latest`.
2. Добавить минимальный USB CDC hello с версией сборки, без датчиков и управления приводом. Проверить linker map: приложение, загрузчик и служебные области не пересекаются. Указать поддерживаемый формат образа и адрес загрузки.
3. Повторить сборку в чистом каталоге. Сравнить значимые артефакты; если есть временные поля, перечислить их. Не требовать одинакового хеша без настройки воспроизводимого build.
4. Только в отдельно заданном аппаратном срезе прошить **указанную** плату штатным способом, сохранив рабочий загрузчик; проверить USB при десяти переподключениях и reset. Не применять mass erase или recovery как рутинный шаг.

## Приёмка

- `PASS` сборки: чистая среда по инструкции получает образ; карта памяти соответствует паспорту; версии и хеш образа сохранены.
- `PASS` устройства: 10/10 переподключений дают новый USB CDC сеанс и ожидаемую строку версии; приложение не зависает при отсутствии ноутбука. Наименование COM записано локально, не зашито в код.
- `FAIL`: неизвестный target/адрес, затронут загрузчик, тест USB заменён успешной компиляцией или заявлен запуск без физического опыта.

**Откат:** хранить проверенный образ и описанный штатный способ возврата. Не обещать возможность восстановления загрузчика без подтверждённого доступа к нему. Сохранить логи неудачного запуска.

**Доказательства:** `evidence/reports/G01.md`: команды, версии, linker map, хеши, результаты каждого USB подключения. Отдельно `build_passed` и `device_passed`.
