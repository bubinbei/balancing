# G02 — протокол, запись и повтор без платы

**Результат:** Python принимает произвольно разбитый поток байтов, проверяет кадры, сохраняет оригинальные данные и воспроизводит сеанс. Уровень: `synthetic`. Плата и COM не нужны.

**Читать:** [README](../README.md), [STATE](../STATE.md), эту карточку, [DATA_PROTOCOL](../docs/DATA_PROTOCOL.md), [VALIDATION](../docs/VALIDATION.md). Пять проектных файлов.

**Файлы:** будущие `host/`, `tests/protocol/`, `tests/fixtures/synthetic/`, `evidence/reports/G02.md`. Не менять wire contract молча: при необходимости сначала новая версия в DATA_PROTOCOL.

## Срезы

1. Реализовать кодек строго по DATA_PROTOCOL: размер, endian, CRC, типы и предел payload. Создать независимые контрольные векторы с ручной проверкой длины/CRC; encoder→decoder одного автора недостаточно.
2. Сделать потоковый parser с ограниченной памятью и восстановлением после мусора. Записывать непрерывный исходный поток и журнал обнаруженных ошибок; не терять исходные повреждённые байты.
3. Добавить сеанс с конфигурацией, последовательностями, временем и качеством. Сброс устройства/новый HELLO начинает новый временной контекст; GAP не превращается в нулевые измерения.
4. Реализовать recorder/replay и тесты разбиения каждого контрольного кадра во всех возможных позициях, склеенных кадров, битовой порчи, неверной длины, обрыва хвоста, неизвестной версии/типа, повторов, пропусков и перестановки sequence. Только после этого предусмотреть транспорт PySerial без его открытия в этом этапе.

## Приёмка

- `PASS`: все независимые валидные векторы разобраны одинаково при любом дроблении; неверный CRC не выдаёт валидный отсчёт.
- `PASS`: после вставки мусора parser находит следующий полный корректный кадр; рост памяти ограничен заданным лимитом, проверяемым тестом длинного мусора.
- `PASS`: 100% вставленных разрывов последовательности/сеанса и незавершённый хвост отражены в качестве; replay совпадает с исходными валидными записями и журналом ошибок.
- `FAIL`: некорректные байты молча пропускаются, объём буфера не ограничен или время прибытия USB заменяет время измерения.

**Откат:** сохранять тестовые входы и предыдущую версию parser; несовместимые версии не преобразовывать поверх исходных файлов. Не исправлять сырую запись на месте.

**Доказательства:** отчёт G02 с командами тестов, известными входами/ожидаемыми полями, seed генератора, размером и SHA-256 fixtures. Везде метка `synthetic`.
