# G07 — математическая обработка

Реализованы [анализ](../../host/balancing_host/analysis.py), [чтение capture](../../host/balancing_host/capture_analysis.py) и CLI analyze/solve. Основной способ — cos/sin-регрессия с DC/трендом по фактическим timestamps и фазе, с известной задержкой каждого канала. FFT предварительно переводит данные на равномерную сетку; пиковая амплитуда нормирована на окно. Синхронное усреднение выполняется по полным оборотам.

Двухплоскостное решение использует все выбранные каналы, real-матрицу четырёх неизвестных, полную ковариацию и whitening. Для ковариации решения используется SVD без обращения A.T*A. Возвращаются ранг, обусловленность, остаток, условная неопределённость и явно настроенные ограничения. Сингулярные/почти неразличимые модели дают отказ.
