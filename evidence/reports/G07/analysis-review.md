# Проверка анализа и 3D, 2026-10-29

Срез G07 по запросу владельца. Проверены `analysis.py`, `capture_analysis.py`, `counterweights.py`, путь синтетического demo и отрисовка. Это проверка программной реализации на synthetic/model_example, не итоговый аудит всего станка и не подтверждение точности на реальном роторе.

## Найдено и исправлено

1. **Фаза синхронного среднего не учитывала задержку датчика.** `harmonic_fit` использовал `t-delay`, а `synchronous_average` и вызывающий его анализ записи — исходное `t`. Пример: 10 Гц, delay=10 мс, истинная фаза 0,4 рад. Раньше среднее возвращало −0,22831853 рад: ошибка −36°. Теперь каждый канал усредняется по своему эффективному времени на общих полных оборотах. Получено 0,40000000 рад, амплитуда 0,99967114 при эталоне 1; малая потеря амплитуды — линейная интерполяция. Проверены разные задержки акселерометра/гироскопа, обратное вращение и сквозная запись BLC1.
2. **Ложный отказ на конце окна при положительной задержке.** После отбора по эффективному времени гармонический анализ повторно вычислял фазу в исходных DRDY timestamps. Последний DRDY мог лежать за последним индексом, хотя сам отсчёт ещё принадлежал окну. Раньше пример выше давал `phase extrapolation is forbidden`; теперь число оборотов считается по эффективным временам всех каналов. Фаза гармоники 0,40000000 рад. Реальная экстраполяция по-прежнему запрещена.
3. **Проверка ковариации зависела от единиц каналов.** Порог собственных чисел применялся к размерной матрице; допустимая смена масштаба могла выглядеть как вырождение. Также абсолютный допуск симметрии скрывал ошибку в малой матрице. Теперь проверка и whitening используют безразмерную корреляционную матрицу с сохранением исходных стандартных отклонений. Решение и его ковариация не меняются при масштабах каналов `[1e6,1e-6,2,100]`; несимметричная матрица порядка 1e-12 отвергается.
4. **Усилена проверка входа.** Бесконечный пробный дисбаланс раньше превращал колонку влияния в ноль; теперь проба должна быть конечной и ненулевой. Для анализа capture требуется один индекс за оборот, согласованное направление индексного/зубчатого входов и наличие событий настроенного зубчатого входа. Отсутствующий зубчатый вход больше не подменяется молча индексным.

Знак комплексного коэффициента `cos(theta+phi) → +phi`, добавляемая коррекция `H*C=-V`, противоположное направление снятия, единицы г·мм и перенос на пару CW с сохранением суммы/осевого момента согласованы в рассмотренных тестах. Ошибки в этих формулах не обнаружены. Это не доказательство отсутствия всех ошибок.

## Изображение

Сортировка граней по средней глубине ошибочно накладывала длинный вал на более близкие детали. Непрозрачный металл теперь использует WebGL depth buffer. Люлька рисуется отдельным прозрачным проходом с проверкой глубины; alpha каждой поверхности 0,18, несколько поверхностей визуально складываются. Контуры и подписи помогают видеть конструкцию. При отсутствии WebGL показывается понятное сообщение, численные результаты остаются доступны.

Увеличены область модели и масштаб; верхние точки длинных подвесов могут быть за границей крупного вида. Сквозной цилиндр заменён пятью участками коренных шеек, связанными через смещённые шатунные шейки/щёки. Вогнутые секторы CW разбиты на выпуклые части. Условные крестики скрываются, если их точки закрыты металлом. Геометрия остаётся учебной, не CAD реальной детали.

## Оставшиеся ограничения

Ковариация solver условна при известной H; она не включает ошибки массы/радиуса/угла проб, изменения монтажа, синхронную силу привода и прочие ошибки модели. Шумовая оценка `harmonic_fit` предполагает белый остаток; реальный коррелированный шум требует повторных прогонов/отдельной модели. Capture пока анализирует один источник из чистой сессии; автоматическая калибровка четырёх реальных датчиков и перенос между режимами не приняты. Одна индексная метка не доказывает угловое ускорение внутри оборота. Выделение 1× на разгоне не равно готовому вычислению коррекции для всего диапазона скорости.

Демо показывает движение заданного генератора, а не восстановленную с прибора 3D-траекторию. Металлообработка по его CW и оценка точности 0,1 г не разрешены/не подтверждены. G07 остаётся in_progress; аппаратные блокировки сохранены.
